# Кабинет клубов

Кабинет — отдельный ASP.NET Core сервер. GitHub Releases распространяет
программу, но не принимает состояние компьютеров. Для работы через интернет
нужны VPS/сервер, домен и HTTPS. Пока сервер не размещён, удалённый кабинет
недоступен; история и уведомления работают локально.

## Локальная проверка

Установите .NET 8 SDK. Задайте `TECHARROW_ADMIN_KEY` — случайный отдельный ключ
не короче 32 символов — через окружение процесса. Не используйте пароль Steam.
Запустите `dotnet run --project src/TechArrow.ClubServer --urls http://localhost:5080`.
Откройте http://localhost:5080 и введите ключ администратора.
Создайте ключ для пары «клуб / компьютер»; он показывается один раз.
На нужном ПК откройте TechArrow → Кабинет клубов, укажите адрес сервера,
введите ключ компьютера и нажмите «Подключить». HTTP поддерживается только
на localhost для локальной проверки, на удалённых компьютерах нужен HTTPS.

## Размещение

Опубликуйте `dotnet publish src/TechArrow.ClubServer -c Release -o artifacts/club-server`.
Сервер запускается на 127.0.0.1 за HTTPS reverse proxy (например Caddy/nginx).
Порт приложения не открывайте в интернет. Прокси должен сохранять HTTPS и
передавать X-Forwarded-For/X-Forwarded-Proto; доверяется локальный прокси.
Задайте постоянный `TECHARROW_DATA_DIR`, закройте доступ других пользователей
к каталогу и включите резервное копирование. Используется один экземпляр
сервера. В данных сохранены хеши ключей устройств, ключи в открытом виде
не сохраняются. Административный ключ передаётся только через окружение.

## Что видно

Клуб, компьютер, версия программы, последняя связь, занятость, статусы
клиентов и десять последних запусков. Компьютер считается без связи после
трёх минут без сообщений; это не доказательство выключения ПК. На сервере
время принятия сообщения задаётся сервером. Ключ можно отозвать в кабинете.
Пути, подробные локальные ошибки, игры, пароли, логи и Steam-сессии не
передаются. Ключ клиента на Windows шифруется DPAPI для текущего пользователя.
Без явного подключения данные не отправляются. Управления компьютерами,
удалённых команд и чужих аккаунтов в этой версии нет.

Локальная история: `%LOCALAPPDATA%\TechArrow\GameUpdater\History\runs.json`,
до 500 запусков, по 200 событий в каждом. Незавершённый запуск после
перезапуска отмечается прерванным, а не успешным. Предупреждения и ошибки
показываются через системный трей не чаще раза в минуту; Windows может
подавлять их своими настройками уведомлений.
